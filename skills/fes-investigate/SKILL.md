# Repository investigation & debugging


Read applicable AGENTS.md rules, manifests, tests, git status and recent changes. Preserve unrelated work.
For a bug: identify observed vs expected behavior, isolate minimal reproduction, trace actual call/data flow.
Use targeted searches and inspect the execution boundary; distinguish hypothesis from observation.
Collect exact failing commands, environment conditions and smallest affected surface.
Do not modify files in a review-only request.
