# Database and migration engineering


Identify data owners, current schema, consumers and read/write lifecycles.
Before migration: assess existing rows, compat window, deployment ordering, backfill and rollback.
Use transaction boundaries intentionally; index according to observed query plans, not guesswork.
Use parameterized queries, principle-of-least-privilege credentials and safe migration testing.
Never mutate production data without explicit approval and verified backups/recovery plan.
