# Performance and reliability
Establish baseline with representative workload and clear metric, then profile the actual bottleneck. Change one hypothesis at a time. Check complexity, DB queries, cache invalidation, concurrency, timeouts, memory and backpressure. Compare before/after data. No invented speedup claims.

## Handoff
Record affected surfaces, concrete work done, executed verification, unresolved risks and next owner. Apply target project policy first.
