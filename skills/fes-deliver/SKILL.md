# Delivery and handoff


Summarize actual outcome, file changes, commands run and results, user-visible behavior and limitations.
Report acceptance criteria individually as passed/blocked/unverified, with evidence locations.
Give executable local run instructions, environment variables without secret values, and rollback
steps if applicable. State whether work is local, committed, pushed, PR-opened or deployed—never conflate them.
Teach the key concepts succinctly for a beginner without hiding technical tradeoffs.
