# Security and engineering review


Inspect actual git diff, architecture and trust boundaries. Evaluate authorization, secret leaks,
injection, file/path safety, dependency risks, data exposure, accessibility and performance.
Prioritize actionable findings with file path, failure scenario, impact and suggested fix.
Re-run affected checks after remediation. Distinguish static inspection from penetration testing.
Do not call self-review independent. Do not run intrusive scans or external security services without authorization.
