# CI and release verification
Select checks from affected modules and repository policy, not every possible test. Use least-privilege CI secrets; differentiate local build, hosted CI, artifact provenance, deployment and observed health. Never deploy, merge, push or modify pipeline privileges without authorization. Record exact candidate revision and rerun after changes.

## Handoff
Record affected surfaces, concrete work done, executed verification, unresolved risks and next owner. Apply target project policy first.
